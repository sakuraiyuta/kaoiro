Run, watch and orchestrate several CLI AI agents at once.

Research prototype. Developed mainly for daily use by the author and members of their laboratory, with no guarantees about maintenance or responses to issues.

Security. An operator credential lets its holder run commands on every machine where agents run. Treat it like an SSH key to those hosts, and read SECURITY.md before deploying.

What it is

kaoiro (kao-iro, “complexion” or “how someone looks”) launches agents such as Claude Code, Codex, Antigravity and Grok Build on hosts it supervises. It derives each agent's state from engine events and draws it as a character with changing expressions, routes permission requests and questions to the browser, and carries the messages agents send each other.

Features

  • State as a face

    Each agent's state is derived from engine events and drawn as a character expression, not inferred from the text it writes.

  • Control from the browser

    Launch, stop and resume agents, and answer permission requests and questions, without touching a terminal.

  • Agents message each other

    Delegations, review requests and approvals between agents are first-class messages, shown in one merged timeline.

  • Multi-host, four engines

    One runner per machine supervises its agents, and Claude Code, Codex, Antigravity and Grok Build share one protocol.
