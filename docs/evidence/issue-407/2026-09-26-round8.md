## Real reconnect controls

`wrapper/codex/test/reply_basis_rejoin.test.ts` uses the actual ServerLink,
Phoenix client, and InterAgentTool with a loopback WebSocket peer. It holds the
first actual network acknowledgement, queues another same-CID invoke, disconnects,
and holds the next join response. The first push times out after ten seconds;
this releases the CID lock but must not dispatch the queued call while pending.
After a v1 join response, that call succeeds with basis 0. Both initial legacy
and initial v1 modes are tested. Old-generation pushes are rejected after rejoin,
and a directory round trip fences the assertion that no old buffered IA arrived.
The third control performs channel-only rejoin on a still-open socket and checks
unbound fire-and-forget IA cannot buffer.

The server peer controls acceptance and join replies; this is a transport and
wrapper integration test, not a real server admission test. Separate server
admission tests remain in the full/focused suites.
