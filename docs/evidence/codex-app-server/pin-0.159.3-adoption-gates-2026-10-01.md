## Snapshot recovery and fallback

The [simplified design](../../plans/issue-468-codex-state-backup.md) treats
backup as a convenience; lossless recovery is not promised. External processes
are not scanned. Managed runner inactive/MainPID-zero/cgroup checks remain,
and snapshot failure still prevents both switch and start. Auth/credentials
are excluded. Switch failure attempts verified source recovery. If snapshot
recovery fails, the runbooks require manual fresh setup with configuration,
instruction links/hooks and a new operator login; there is no automatic reset.

The final built archive for `c4cf6fa1` passed strict verification and native
resolver equality. Real owned systemd units ran source `f0808401` → target
`c4cf6fa1` → restored source. Both are native 0.159.3: this is a real built
state-aware update/restore, not a new cross-version migration experiment.
Each worker exited 0 and actual runner joins progressed 1 → 2 → 3.
Synthetic history was restored. The separate service-fixture round trip also
confirmed source-child removal and retention of current synthetic credentials.

A native exec thread was created **after** the snapshot through a local provider.
After restoration, sending its retained ID through the actual runner's spawn
path returned `session_not_found`, with no wrapper join. Explicit fresh spawn
then returned ok and completed one native local-provider turn. The two local
provider requests (post-snapshot seed and fresh turn) are not live model turns.
[Earlier native DB observations](pin-0.159.3-native-state-2026-10-01.md) remain
historical, not a requirement to reopen migrated state with the old binary.

Manual destructive fresh-home setup and operator login are not automated or
performed against production in this evaluation. The authenticated candidate
home was separately created and logged in by the operator for gate 5. Metadata
classification of the production home still needs separate operator approval.
After actual rollout, production Codex startup/history acceptance is required;
these isolated tests do not provide that acceptance.
