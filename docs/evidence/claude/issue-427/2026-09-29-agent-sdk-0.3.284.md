# Claude Agent SDK 0.3.284 rollout observations

Measurements were taken on 2026-09-29 in `worktrees/momo-427`. The wrapper
dependency changed from `@anthropic-ai/claude-agent-sdk` 0.3.280 (bundled CLI
2.1.280) to 0.3.284 (CLI 2.1.284). `npm view` reported version 0.3.284 and
`claudeCodeVersion` 2.1.284. The catalog driver supplied no user-message text:
its retained source uses a never-yielding prompt, awaits only
`initializationResult()`, and closes the session. The absence of a
model-generation turn is code-derived; no independent HTTP request counter was
captured, so this does not rule out side effects from loaded user settings. The
host input capture used a local loopback endpoint. The resolved SDK entry
`sdk.mjs` has SHA-256
`32d062c37b03e10870fbf839f54694545ee01bc0ec719e47078fbed76e30ef71`.

## Agent instructions and state projection

An AGENTS-only scratch project was started through the real Claude host and
SDK 0.3.284 with the host's default query options; the host does not set
`settingSources`. The project contained only `AGENTS.md` before and after the
run. In the first loopback `POST /v1/messages`, the marker was absent; in the
second, it appeared in `messages` and not in `system`. The second request body
was 101,461 bytes with SHA-256
`cd2d5fc36b72a49b0b41c2e8987dc8c5ad31c7711f2f7f7b75aba4dc755e0cc2`; the
first was 3,978 bytes with SHA-256
`abe5a6c9333138063a2483ada726c3b9670b0286126f62cc52c0f2fe769601aa`. The
local stub returned a canned response, the host exited `0`, and the isolated
scratch project was removed. This confirms the marker reached the outbound
request in `messages`; it does not establish how a remote provider would use
it. Raw request metadata and the sanitized summary are listed in the
`tmp/reviews/issue-427/momo-recapture-r2.md` manifest.

The scripted Sonnet 5.5 adapter test substitutes a `thinking` block for a
`text` block between the same tool events. Both inputs produce the same coarse
state trace; the thinking block is not emitted as a transcript log. This is a
mapping test, not a measurement that a live Sonnet 5.5 response emits either
content-block shape.
