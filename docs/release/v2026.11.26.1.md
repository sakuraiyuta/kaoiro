## Experimental Muse engine

Muse Code is available as an experimental engine. The launch dialog marks
it experimental. Model selection is available at launch; live model and
effort switching and the kaoiro permission selectors are unsupported.
Muse uses the ACP `promptUnmatched` approval mode. A persona is supplied
in the prompt and its delivery is tracked for recovery.
[PR 1270](https://github.com/sakuraiyuta/kaoiro/pull/1270),
[PR 1272](https://github.com/sakuraiyuta/kaoiro/pull/1272),
[issue #1276](https://github.com/sakuraiyuta/kaoiro/issues/1276)

The effect of `--model` on a real Muse build is unmeasured; the effective
model and effort are reported only from ACP responses, not verified as
effective values. With workspace trust enabled,
real-provider `tools/call`, approval enforcement during tool execution, and
MCP after cold resume are unmeasured. Recovery from a runner-detected failure
to the same session ID and persona retention after compaction are unmeasured.
Server retention of the effort warning has not been tested in a Muse-specific
integration.
A runner restart or a crash before delivery is recorded can cause the
persona to be sent again. See the
[Muse reference](../reference/engines/muse-acp.md).

## Agent grid rooms

Room headers can fold and unfold their live agent tiles. A folded header
shows the live count and aggregate state; hidden tiles cannot be operated.
The preference is stored in the browser and defaults to open. Folding
does not change room membership or agent state.
[Issue #1273](https://github.com/sakuraiyuta/kaoiro/issues/1273)

## Upgrade and recovery

1. Follow the high-risk release procedure for both FS and TL, including
   the production-shape start gate and fleet restoration checks.
2. To use Muse, install the Muse CLI on the runner host and run
   `muse login`. Muse is available without a new runner setting.
3. To use kaoiro tools with Muse, opt in for a trusted workspace by setting
   `KAOIRO_MUSE_TRUST_WORKSPACE` in the wrapper environment. This also loads
   workspace skills and rules. If set in `runner.env`, restart the runner
   and affected wrappers. Without trust, Muse does not start MCP servers.
