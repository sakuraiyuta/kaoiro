# Release v2026.11.04.1

- Previous production release: [v2026.11.01.1](v2026.11.01.1.md) (`c615ea60`, server and runner)
- Range: `v2026.11.01.1..v2026.11.04.1`
- Release class: neither FS nor TL
  ([High-risk change release](../operations/high-risk-change-release.md)).
  The product change is limited to dashboard styling. No `runner/src`,
  `wrapper/*/src` or server application file changed, and no SDK, CLI or
  native pin changed.

## Highlights

- **Dashboard controls follow the design by default.** A zero-specificity
  baseline in `app.css` gives native buttons, inputs, selects, links and
  headings the design tokens, so a new control no longer starts from the
  browser defaults. The session history dialog, the per-agent session history
  button, the delivery policy panel, the work settings section and the grid
  sort setting now match the rest of the dashboard
  ([issue #961](https://github.com/sakuraiyuta/kaoiro/issues/961)).

## Changes

### Dashboard

- Disabled inputs, selects and textareas are shown with dim text on the card
  background.
- Work settings alerts use the error colour and status lines use the normal
  text colour.
- Undefined CSS variables and hard-coded colours are replaced with design
  tokens, and text weights stop at 600.
- The grid sort label stacks above its select, which no longer overflows the
  settings drawer.

### CI and tests

- `test-isolation` is the only normal execution path for the canonical Node
  entries; the `server-deploy` job and the trailing explicit four-file step
  are removed, so CI runs six jobs
  ([issue #693](https://github.com/sakuraiyuta/kaoiro/issues/693)).
- The wrapper CI job and test diagnostics for issue #949 changed; no product
  behaviour changed.

### Documentation

- ADR-0050 D9 records that no dedicated graph editing client is planned
  ([issue #191](https://github.com/sakuraiyuta/kaoiro/issues/191)).
- Automatic runner update and rollback are documented as Linux with systemd
  only; macOS is supported for the initial install
  ([issue #242](https://github.com/sakuraiyuta/kaoiro/issues/242)).

## Operator steps

- Only the server changes in product terms, so the dashboard reaches operators
  through the server update. Updating the runner keeps the versions aligned
  but delivers no new runner or wrapper behaviour.
- No new environment variable, no new server store and no stored format change.
  The deploy CLI does not ask to accept a new store.
- Rolling back to v2026.11.01.1 restores the previous dashboard styling. No
  server state depends on this release.
