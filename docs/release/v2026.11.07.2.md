# Release v2026.11.07.2

- Previous production release: [v2026.11.07.1](v2026.11.07.1.md)
- Range: `v2026.11.07.1..v2026.11.07.2`
- Release class: TL
  ([High-risk change release](../operations/high-risk-change-release.md)).
  The Claude Agent SDK pin changes, which no path rule catches, so the
  claude-code engine is affected. `wrapper/agent-common/src/inter_agent.ts`
  is on the turn-lifecycle list and is shared by every engine.
  `<1051+1052: name the listed files, or remove this sentence>`

## Highlights

- **Claude Code peers run on Agent SDK 0.3.319**, which bundles Claude Code
  2.1.319 (previously 0.3.306 and 2.1.306). Several permission, hook and
  model-switch behaviours change; see [Claude Code](#claude-code)
  ([issue #1044](https://github.com/sakuraiyuta/kaoiro/issues/1044)).
- **`kind=done` without a `done` argument ends the conversation.** An omitted
  `done` now defaults to true for `kind=done` and to false for every other
  kind. An explicit boolean is sent unchanged
  ([issue #665](https://github.com/sakuraiyuta/kaoiro/issues/665)).
- **A directory store failure answers the request instead of dropping the
  wrapper channel.** `directory_request` replies with the new reason
  `directory_unavailable`
  ([issue #675](https://github.com/sakuraiyuta/kaoiro/issues/675)).

## Changes

### Claude Code

- The Agent SDK is 0.3.319 and the bundled CLI is 2.1.319. The changelog
  reads, the input-folding re-measurement and the init-only catalog probe
  (13 rows, unchanged) are recorded in the
  [0.3.319 evidence](../evidence/claude/issue-1044/sdk-0.3.319-2026-11-07.md).
  These behaviour changes come from the vendor, not from kaoiro:
  - 2.1.307: a model switch through `setModel()` waits up to 15 seconds,
    rather than 5, for the API to confirm the model. A model switch from the
    dashboard can take that long to settle.
  - 2.1.319: Bash deny and ask rules now cover commands written with quoted
    words, a `sed` path in accept-edits and auto mode, `which` with flags
    outside a lookup set, and an environment-prefix bypass. A peer may now be
    asked about commands that previously went through.
  - 2.1.319: Monitor's WebSocket watch follows Bash rules. A deny refuses it,
    and under an ask rule neither an allow on Monitor, nor bypass mode, nor
    auto mode skips the prompt.
  - 2.1.314: hooks that match Bash also run on shell commands the Monitor tool
    starts, and `Monitor(...)` conditions match them as `Bash(...)` does.
  - 2.1.316: fast mode for Opus 4.8 is deprecated and is removed on
    2026-11-30. After that, a fast-mode request on Opus 4.8 returns an error
    and does not fall back to standard Opus 4.8. A peer that runs Opus 4.8
    with fast mode, for example after a model fallback, is affected. This
    release does not change that date.

### Inter-agent messages

- `send_to_agent` resolves an omitted `done` from the kind once, and uses the
  same value for `meta.done` and for this side's own close state. Admission
  still reads `meta.done` only
  ([messages](../reference/inter-agent/messages.md),
  [issue #665](https://github.com/sakuraiyuta/kaoiro/issues/665)).

### Server

- When a directory store does not answer, `directory_request` returns
  `directory_unavailable` for both the ordinary and the `self` scope, and the
  wrapper channel stays joined. The server log names the store; the reply
  does not. The request can be retried. In a peer, `list_agents` fails with
  this reason and `whoami` reports the name as unknown
  ([channels](../reference/protocol/channels.md),
  [issue #675](https://github.com/sakuraiyuta/kaoiro/issues/675)).

## Operator steps

- Update the server and the runner to the same commit. The server change works
  with the previous wrappers, and the new wrappers work with the previous
  server, so the order is not forced.
- The release is TL. Run the start gate (recommended for TL), then follow
  [Release and restore the fleet](../operations/high-risk-change-release.md#4-release-and-restore-the-fleet).
  After restoration, check one turn on a Claude Code peer and one on each other
  engine.
- No new environment variable, no new server store and no stored format
  change. The persona packs do not change.

## Rollback

- Roll the server and the runner back to v2026.11.07.1 with the usual
  procedures. The Claude Agent SDK returns to 0.3.306 with the runner release.
  No state migration is involved.
