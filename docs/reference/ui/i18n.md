# Dashboard i18n contract

The bundled dashboard shows its own text in Japanese or English. Decision and
rejected alternatives: [ADR-0071](../../adr/0071-dashboard-i18n.md). How to add
text: [Dashboard strings](../../contributing/dashboard-strings.md).

Until the migration of [issue #269](https://github.com/sakuraiyuta/kaoiro/issues/269)
is complete, screens that are not migrated yet are Japanese in both languages.

## Languages

`ja` and `en`. The table of a language is a typed object under
`dashboard/src/lib/i18n/<language>/`. The ja tables define the type; the en
tables must match it key for key and argument for argument (`pnpm check`);
an en function declares the parameter of its ja counterpart even when unused.

## Resolution and storage

| Setting `locale` | UI language |
|---|---|
| `ja`, `en` | That language |
| `auto` (default) | The first entry of `navigator.languages` whose primary subtag is `ja` or `en`; en when there is none |

| `navigator.languages` | `auto` result |
|---|---|
| `["ja-JP", "en-US"]` | ja |
| `["en-US", "ja"]` | en |
| `["fr", "ja"]` | ja |
| `["fr"]`, `[]` | en |

- The setting is a field of the `kaoiro:settings:v1` localStorage entry. An
  invalid value, or an entry without the field, reads as `auto`; a browser
  without usable localStorage runs with `auto`.
- `auto` is resolved once, when the page loads. A later change of the browser's
  language is not followed.
- The language is changed from the login screen and from the settings drawer
  (`Auto`, `日本語`, `English`; the last two are shown the same under every
  language). A choice repaints the page without a reload.
- `<html lang>` follows the UI language.

## What is translated

Text the dashboard writes itself: labels, buttons, `aria-label` / `title` /
`placeholder`, confirmation dialogs, notices, relative times ("3 minutes ago").

Not translated, shown as received: agent names, persona names, room names and
other names an operator chose, `agent_id`, engine and model names, wire values
(for example `read-only`), codes and messages from the server, and the text of
agents.

## Dates

Four absolute date and time displays are formatted for the UI language
(`ja-JP` or `en-US`, 24-hour clock): the status line time on the agent card
and in its panel, the status line history dialog and the device approval
issue time. The other absolute dates follow the browser's own settings, so
an English UI in a Japanese browser shows them in the Japanese format.

## What does not follow a switch

- Text built when an event happens and then kept in state, such as a login
  error or a notice that is already shown, keeps the language it was built in
  until it is built again.
- Anything read outside a function, template or `$derived` is frozen at the
  language of that moment; the code rule that prevents it is in
  [Dashboard strings](../../contributing/dashboard-strings.md).
